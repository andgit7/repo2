1. scrab.py - парсинг страницы
Назначение: загружает страницу grandtrain.ru в headless Chrome и сохраняет HTML.

Особенности:

Использует Selenium с ChromeDriverManager (автоустановка драйвера)

Работает в headless-режиме

Маскирует автоматизацию (убирает флаг webdriver)

Сохраняет полный HTML в /home/and/pars5/snapshot/parsed_page.html

Проблемы в логе:

HTML размером всего 3839 символов — это слишком мало для страницы с поездами. Видимо, страница не загрузилась полностью (возможно, нужна авторизация или динамическая подгрузка через JS).

2. workv2.sh - извлечение блока поезда
Назначение: из parsed_page.html вырезает блок конкретного поезда (по умолчанию 018М).

Особенности:

Ищет data-number="018М" в HTML

Аккуратно подсчитывает вложенные <div> для корректного вырезания

Добавляет информативный заголовок

Выводит сводку по местам (классы, места, цены)

Результат: сохраняет в train.html.

Проблемы:

Если parsed_page.html неполный (3839 байт), то поезда могут не найтись или вырезаться некорректно.

В train.html видно, что блок неполный — есть </div></div></div> в конце, но структура нарушена.

3. ex6.sh - парсинг мест
Назначение: извлекает количество свободных мест из train.html.

Особенности:

Находит строки с seats_item

Вырезает блок из 15 строк вокруг

Парсит train_seats_count (например, 16&nbsp;низ, 44&nbsp;верх)

Извлекает цифры: сначала "нижних", потом "верхних"

Результат: сохраняет в result.txt:

text
Плацкарт: нижних 16, верхних 44
Купе: нижних 154, верхних 194
СВ: нижних 9, верхних 0
Проблема: в train.html первый блок поезда дублируется (два раза), что может сбивать парсинг.

4. tgbot_scrn.sh - мониторинг и уведомления
Назначение: сравнивает текущие данные с предыдущим снимком и отправляет изменения в Telegram.

Особенности:

Извлекает только строку с "Плацкарт: нижних" из result.txt

Сравнивает с grand_snapshot.txt (предыдущее состояние)

Если изменения есть > отправляет:

Текст изменений (через URL-кодирование)

Скриншот (screenshot.png)

Обновляет снимок после сравнения

Проблемы:

Сравнение через awk работает только если количество строк одинаково. Если строка "Плацкарт" отсутствует в одном из файлов — awk выдаст ошибку или неправильный результат.

Отправка текста через url — если в тексте есть спецсимволы, они могут сломать запрос.

В result.txt три строки, а в grand_snapshot.txt — одна. Сравнение через awk не эквивалентно.

5. main.sh - оркестратор
Назначение: последовательно запускает все скрипты, логирует и выводит цветной отчёт.

Особенности:

Проверяет наличие файлов

Запускает scrab.py, workv2.sh, ex6.sh, tgbot_scrn.sh

В случае ошибки прерывает выполнение

Логирует в cron.log
